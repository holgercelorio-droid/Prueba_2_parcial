# Sistema de Gestión de Catálogo de Productos

Proyecto desarrollado para la evaluación del Segundo Parcial en la asignatura de Programación.

## Descripción
Esta aplicación permite registrar y gestionar un catálogo de productos a través de una interfaz gráfica desarrollada en Python utilizando Flet, con almacenamiento persistente en una base de datos SQLite.

## Requisitos
- Python 3.x
- Librería `flet`
